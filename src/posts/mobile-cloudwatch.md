![Mobile Cloudwatch Android app](/posts/images/mobile-cloudwatch.png)

At the left you can see the result of some weeks of hacking on the train. This is a fully working application, if you had a phone running android (like the G1, sold starting 22nd October) you could begin using it.

The screenshot shows various settings and the current cloud status (CLOUDED). This cloud status is collected by connecting from time to time (defined by the feed, usually about 5 mins) to the cloudwatch.net website.

In the top status bar you can see a cloud alert just went off, this is accompanied by an audible alert.

Since there is no hardware to run it on (yet) we'll have to wait a bit to test this, let me know if you have one!
